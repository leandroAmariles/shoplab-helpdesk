# Qué datos recogemos y para qué se usan

## Alcance
Este documento detalla cada categoría de dato personal que ShopLab recoge, para qué se usa y cuánto tiempo se conserva.

## Cómo funciona
| Categoría | Ejemplos | Para qué se usa |
|---|---|---|
| Identificación y contacto | nombre, correo de contacto | gestionar la cuenta y dar soporte |
| Dirección de entrega | calle, ciudad, estado, código postal | entregar los pedidos |
| Historial de pedidos | productos, importes, estados | gestionar pedidos, devoluciones y garantías |
| Datos de pago tokenizados | referencia del medio de pago, sin número completo | procesar pagos |
| Valoraciones | puntuación y comentario de un pedido | mejorar el servicio |

## Plazos y costos
- Datos fiscales: se conservan 5 años.
- Datos de la cuenta: se conservan hasta que pidas su eliminación.
- No hay costo por consultar o gestionar tus datos.

## Casos especiales
- **Asistente de ShopLab**: las conversaciones con el asistente se usan para responder tu consulta y para mejorar el
  servicio. No compartas datos que no sean necesarios, como contraseñas o el número completo de una tarjeta.
- **Datos de ejemplo**: los datos de ejemplo con los que se prueba el sistema son anonimizados y no corresponden a
  clientes reales.
- ShopLab no vende datos a terceros.

## Contacto

formulario de contacto del sitio. Atención de lunes a viernes, de 9:00 a 18:00 (hora de Brasilia).
