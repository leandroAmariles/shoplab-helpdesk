# Seguimiento del pedido

## Alcance
Este documento explica cómo saber dónde está un pedido y qué significa cada estado que se muestra en tu cuenta.

## Cómo funciona
Dentro de las 24 horas siguientes al despacho, ShopLab envía por correo un código de seguimiento. Con ese código puedes
consultar el recorrido en el sitio del transportista. También puedes ver el estado del pedido en tu cuenta o preguntarle
al asistente de ShopLab con el número de pedido.

## Plazos y costos
El código de seguimiento llega dentro de 24 horas tras el despacho. Consultar el seguimiento no tiene costo.

## Estados del pedido
| Estado | Significado |
|---|---|
| `created` | pedido creado, pago pendiente |
| `approved` | pago aprobado |
| `invoiced` | factura emitida |
| `processing` | preparación en almacén |
| `shipped` | entregado al transportista |
| `delivered` | entregado al cliente |
| `unavailable` | sin stock tras la compra |
| `canceled` | cancelado |

## Casos especiales
- Hasta que el pedido llega a `shipped` no existe código de seguimiento.
- Si el estado no cambia durante varios días, consulta el documento "Plazos de entrega" para saber si sigue dentro del
  plazo.
- Un pedido `unavailable` se cancela y se reembolsa automáticamente (ver "Cambios y cancelaciones").
